📥 Unduh Installer Agent Siap Pakai

Paket ZIP ini sudah otomatis terkonfigurasi dengan alamat server dan nama cabang Anda. Komputer yang menjalankan installer ini akan otomatis masuk ke daftar inventaris cabang yang dipilih.

Komputer akan otomatis terdaftar sebagai aset cabang ini.
🚀 Cara Pakai (Sangat Mudah):
  1. Ekstrak isi file ZIP ke folder di komputer cabang (misal: C:\RemoteDesk\).
  2. Klik dua kali pasang-otomatis.bat, lalu klik Yes satu kali pada permintaan Administrator.
  3. Selesai! Agent aktif tersembunyi dengan hak tertinggi dan otomatis jalan setiap kali user Windows login.

Atur daftar lokasi cabang, bisnis unit, service point, pool, atau site. Lokasi ini akan otomatis muncul di dropdown Download Agent.
